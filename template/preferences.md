# Preferences

How I want to be worked with. Injected into every session in *every* project, not just this
vault. Hard ceiling: 30 lines — anything longer is a tax on all your work.

## Response style
- Answer first. No warm-up paragraph, no restating the question.
- Concise by default. Medium detail for code — correct and clear, not verbose.
- Say when something is uncertain or out of date rather than guessing confidently.

## Code
- Production-quality by default: error handling, types, no placeholder stubs.
- Read a file before editing it.
- Don't add dependencies without saying why.
